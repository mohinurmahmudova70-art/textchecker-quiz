# TalabaPlan APK

1. github.com ga kiring va yangi repository oching (nomi: talabaplan, Public yoki Private).
2. "uploading an existing file" havolasi orqali shu papkadagi BARCHA fayllarni yuklang
   (www papkasi, package.json, capacitor.config.json, .gitignore va .github papkasi).
   Muhim: .github/workflows/build-apk.yml fayli oʻz joyida boʻlishi kerak.
3. Repository ichida Actions bandini oching. "APK yigʻish" ishi avtomatik boshlanadi
   (boshlanmasa: oʻsha ishni tanlab "Run workflow" tugmasini bosing).
4. 5–10 daqiqadan keyin ish yashil boʻladi. Uni oching va pastdagi Artifacts boʻlimidan
   TalabaPlan-apk ni yuklab oling (zip ichida app-debug.apk).
5. APK ni telefonga koʻchiring va oching. Android "nomaʼlum manba" haqida soʻrasa, ruxsat bering.
